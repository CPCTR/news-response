# 開發日誌 — 2026-06-16

## 專案
石化廠（台灣中油桃園煉油廠）新聞稿撰寫助理 — 參加 AI 競賽，已過初選，進入第二輪。
核心定位：**事件 → 速報事實 → 判斷是否對外 → 套版型生成草稿 → 人工修改 → 回填學習**（愈用愈聰明的複利閉環）。雙模型：Sonnet 撰稿 → Opus 4.8 校正。

## 今日決策（含第一性原則的取捨）
- **不擴充通用輿情監控**：資料只有歷史新聞稿、無即時資料源，真功能無法 demo。監控只放 roadmap，demo 全力演核心閉環。
- **20 篇不做 RAG**：資料量遠小於 context 上限，改用「結構化全文載入 / 案例卡」，架構設計成 RAG-ready 待規模成長再切換。
- **產品主軸重定義**：工安速報＝新聞稿的「事實底稿」，不是單純的學習資料。流程改為「速報 → 去識別化＋語氣加工 → 新聞稿」。
- **隱私兩道防線**：原始 `doc/` 不進 git；生成時不得把個資寫入對外稿（憲法條目六）。
- **沿用中油現成的三份官方範本**，不自創格式：輿情預警通報表（輸入/判斷）、空白新聞稿（輸出版型）、災害速報表（事實底稿）。
